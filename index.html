The nitra project

Bienvenido al proyecto nitra, un proyecto sin ánimo de lucro cuyo objetivo es ofrecer a los usuarios un portal para acceder a servicios y software, todo enrutado a través de la red tor, lo que garantiza el anonimato y el cifrado entre el cliente (Usted) y el servidor (Nosotros) gracias al sistema de la red tor.
También tenemos un sitio web en la clearnet gracias a GitHub Pages. Sinembargo, desde esta plataforma te ofrecemos servicios exclusivos.
En definitiva, si quieres un servicio que no comparta tus datos personales con nadie, ni si quiera con tu ISP, este es otro camino para acceder a nuestros servicios.
